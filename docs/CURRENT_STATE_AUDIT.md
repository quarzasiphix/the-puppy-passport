## 1. Framework & project structure

- **TanStack Start** (React 19, SSR via `@tanstack/react-start`/nitro), file-based routing via
  `@tanstack/react-router`, built through `@lovable.dev/vite-tanstack-config` (Vite 8 + a
  `rolldown`-based bundler). Package manager: npm (a `bun.lock` also exists from the original
  Lovable scaffold but isn't used).
- **Routing**: 98 route files under `src/routes/` as of 2026-07-22 (grown considerably since this
  section originally said 38), file-based (`_public.*` = public layout, `dashboard.buyer.*` /
  `dashboard.breeder.*` = dashboards, `__root.tsx` = root shell + auth-hydrating `beforeLoad`).
  `src/routeTree.gen.ts` is generated by the router's Vite plugin on every `vite dev`/`vite build`
  run. **This section originally warned the tree "may be stale" — re-verified 2026-07-22 and that
  turned out to be unfounded**: a real `npm run build` regenerates it, and every one of the 98
  route files is represented in the generated tree, confirmed by direct comparison.
- **Component structure**: shadcn/Radix primitives in `src/components/ui/*` (accordion through
  tooltip — the full shadcn set), shared marketplace cards in `src/components/cards.tsx`
  (`PuppyCard`/`LitterCard`/`BreederCard`), site chrome in `src/components/site-chrome.tsx`
  (`SiteHeader`/`SiteFooter`, auth-aware with a mobile `Sheet` menu).
- **Styling**: Tailwind v4 via `@tailwindcss/vite`, custom design tokens in `src/styles.css`
  (CSS variables for the `font-display`/color palette), `tw-animate-css`.
- **Responsive behaviour**: pages lean on Tailwind's responsive utility classes (`md:`/`lg:` grid
  columns throughout). The header's mobile nav `Sheet` is real and functional.

## 5. Environment variables & external integrations

- `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` — required, read in
  `src/lib/supabase/{browser,server}.ts`, throw a clear error at client-construction time if
  missing (no silent fallback).
- `SUPABASE_AUTH_GOOGLE_CLIENT_ID`/`_SECRET`, `SUPABASE_AUTH_FACEBOOK_CLIENT_ID`/`_SECRET` —
  optional, referenced by `supabase/config.toml`'s `env(...)` interpolation for OAuth providers
  (both `enabled = false` until real credentials exist — **requires external configuration**, see
  `docs/SOCIAL_AUTH_SETUP.md`).
- No payments, maps beyond the now-built breeder map, email service, or AI provider integration
  exists.
